# TEST BASE

Небольшая система тестирования на HTML, CSS и JavaScript для размещения на GitHub Pages.

## Возможности

- Каталог тестов с поиском и фильтром по категориям.
- Банк вопросов в JSON.
- Случайная выборка вопросов и перемешивание вариантов ответа.
- Таймер, навигация и возможность менять ответы.
- Экзаменационный режим: фиксация ухода со страницы, предупреждения и автозавершение при достижении лимита.
- Сохранение текущей попытки и оставшегося времени в sessionStorage при перезагрузке той же вкладки.
- Экран результата: баллы и оценка.
- Адаптивный интерфейс.

## Структура

- `index.html` — каталог.
- `test.html` — прохождение теста.
- `result.html` — результат.
- `admin.html` — памятка по редактированию.
- `data/tests.json` — каталог и настройки тестов.
- `data/questions.json` — банк вопросов.
- `css/style.css` — оформление.
- `js/` — логика страниц.

## Добавление теста

1. Добавьте тест в массив `tests` файла `data/tests.json`.
2. Добавьте вопросы в массив `questions` файла `data/questions.json`.
3. У каждого вопроса задайте уникальный `id`, тот же `testId`, текст, четыре ответа и `correct` — индекс правильного ответа от 0 до 3.
4. В `questionCount` задайте желаемое количество вопросов. Если оно больше количества доступных вопросов, будут использованы все вопросы.

## Публикация через GitHub Pages

1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Выберите ветку `main` и папку `/(root)`.
4. Сохраните настройки. После публикации сайт будет доступен по адресу `https://vladtrosko01.github.io/test-base/`.

## Ограничения безопасности

Это статический клиентский проект. Все JSON-файлы доступны посетителям, поэтому правильные ответы в `data/questions.json` можно извлечь из исходников. JavaScript-ограничения не могут надёжно остановить DevTools, скриншоты, второе устройство или изменение кода браузера. Не используйте этот вариант для экзаменов, где требуется конфиденциальность ответов, проверяемая личность или доказуемая защита от списывания. Для этого необходим сервер, который хранит ключи ответов и проверяет попытки.
