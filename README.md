# TEST BASE

Статическая система тестирования для GitHub Pages.

## Возможности
- Каталог тестов с поиском и фильтром.
- JSON-банк вопросов с браузерным редактором.
- Настройки каждого теста: количество вопросов (случайно из диапазона, фиксированное или все), время, проходной процент, перемешивание.
- Экзаменационный режим: контроль ухода со страницы, лимит нарушений и обязательный Fullscreen API.
- При выходе из fullscreen экзамен автоматически завершается.
- Навигация между вопросами и экран результата с зачётом/незачётом.

## Настройка
Откройте страницу «Управление». Измените параметры выбранного теста и нажмите «Сохранить настройки в редакторе». Скачайте `tests.json` и загрузите его в `data/tests.json` в GitHub. Банк вопросов редактируется отдельно; его можно выгрузить в `questions.json`.

## Публикация
В Settings → Pages выберите Deploy from a branch, ветку `main` и папку `/(root)`.

Сайт: https://vladtrosko01.github.io/test-base/

## Ограничения
GitHub Pages — статический хостинг. Все данные JSON доступны посетителю, поэтому правильные ответы можно извлечь из исходников. Браузерный контроль fullscreen и вкладок не является надёжной защитой от обхода и не заменяет серверную проверку. Fullscreen API поддерживается не всеми браузерами и требует явного действия пользователя. Если браузер не разрешает полноэкранный режим, экзамен не запускается.
