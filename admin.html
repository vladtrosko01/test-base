Как опубликовать обновлённую базу

  1. Добавьте или удалите вопросы в редакторе.
  2. Нажмите «Скачать JSON». Файл сохранится на компьютер.
  3. Откройте папку data в GitHub.
  4. Откройте questions.json, нажмите карандаш или используйте Add file → Upload files, чтобы заменить его скачанным файлом.
  5. Сохраните изменения в ветку main. После обновления GitHub Pages сайт загрузит новую базу.
