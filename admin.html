Управление тестами

Просмотр структуры JSON и инструкция по добавлению материалов.

Важно: GitHub Pages — статический хостинг. Эта страница не может безопасно записывать изменения в репозиторий. Для изменения тестов отредактируйте JSON-файлы в GitHub.

Файлы базы данных

data/tests.jsonКаталог, параметры и описания тестовОткрыть ↗data/questions.jsonБанк вопросов и варианты ответовОткрыть ↗

Как добавить тест

  1. Добавьте объект теста в data/tests.json.
  2. Укажите уникальный id, название, категорию и настройки.
  3. Добавьте вопросы с таким же testId в data/questions.json.
  4. Для каждого вопроса укажите четыре ответа и индекс правильного ответа от 0 до 3.
  5. Сохраните изменения в ветку main. GitHub Pages обновит сайт автоматически после публикации.
